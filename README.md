## ✨ 项目特色

- **双主题切换**
  - ☀️ **白天模式**：热带沙滩风格（蓝天/海浪/椰子树）
  - 🌙 **夜间模式**：深海潜水摸鱼风格（气泡上升/游鱼/荧光）
  - 顶部开关一键切换，温度进度条随之变为海浪动画 / 深海气泡

- **严格温度公式**
  ```
  市场温度 = (上涨家数 − 下跌家数) ÷ 下跌家数
  ```
  - **1.30 ~ 1.50**：温和上涨（波段最佳）
  - **< 1.30**：热度不足
  - **> 1.50**：过热警示

- **多市场观察列表**（共 11 项）
  - 🇨🇳 A 股 4 项：上证指数 / 深证成指 / 创业板指 / 沪深 300
  - 🇭🇰 港股 3 项：恒生指数 / 恒生科技 / 腾讯控股
  - 🇺🇸 美股 4 项：纳斯达克 / 标普 500 / 道琼斯 / 费城半导体

- **板块复盘框架**
  - 主力净流入 TOP 5 / 主力净流出 TOP 5
  - 涨幅 TOP 5 / 跌幅 TOP 5
  - 近 5–10 日市场温度 & 板块热点历史折线图（每日收盘自动累积）

- **自选股管理**
  - 搜索（代码 / 名称）
  - 添加 / 删除 / 清空
  - localStorage 持久化
  - 行情自动匹配全 A 5534 只股票池

- **8 维信号判断**：每项可点击循环切换 `买入 / 卖出 / 观望`

- **战法匹配 & 风控确认**
  - 3570 建仓 / 3221 止盈闭环
  - 风险收益比自动判定

## 🚀 快速开始

### 方式一：纯静态部署（推荐）

1. 直接用浏览器打开 `index.html` 即可（自动跳转到 17-tropical 主题）
2. 或者部署到任意静态托管：
   ```bash
   # GitHub Pages
   # Vercel
   # Netlify
   # Nginx
   ```

### 方式二：拉取实时数据

```bash
cd monitor20
python fetch_market_data.py
```

脚本会：
- 从新浪财经 / AKShare 抓取全市场涨跌家数（多源交叉核对）
- 抓取 11 项多市场实时行情（A 股 / 港股 / 美股）
- 抓取 5534 只 A 股全量股票池
- 抓取 387 个题材板块资金流 → 4 个榜单
- 追加当日历史快照到 `daily_snapshots.json`

## ⚠️ 已知限制

1. **`data.json` 体积较大**（≈ 571KB），首屏加载需要 1–2 秒，已优化为同步加载 + 本地缓存
2. **网络代理环境**下部分接口（东财、Tushare）不可达，脚本会自动降级
3. **历史快照需手动每日运行** `fetch_market_data.py` 累积，2 条以上即可显示走势图
4. **纯前端项目**，无后端服务、无数据库、无鉴权，适合个人使用或内网部署
